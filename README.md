# Moo-ney · 牛马打气机

Moo-ney 把小牛的叫声 **Moo** 和 **Money** 拼在一起。填写月薪和工作时间，就能在桌面看着收入一点点增长。

一款使用 C# / WPF 编写的 Windows 桌面计时工具，带卡通打工人动效、收入估算和下班倒计时。

## 下载与运行

前往 [Releases 下载正式版](https://github.com/Zaiferater/Moo-ney/releases/latest)，下载 Windows ZIP 压缩包，解压后双击 `牛马打气机.exe`。

已在 Windows 11 64 位环境验证。应用使用 .NET Framework，图标和动效资源已内嵌，运行时可离线使用。

首次启动会打开设置页。填写月薪、上下班时间并保存后，下次启动直接显示计时窗。

## 功能与操作

- 显示今日已赚、本月已赚、下班倒计时和放假倒计时。
- 默认按周一至周五计薪，也可在自定义日历中取消假期、勾选周末补班日，支持跨月编辑。
- 单击角色，在完整计时窗和圆形小窗之间切换，过渡带缩放和淡入淡出。
- 拖动角色移动窗口，位置会自动保存。
- 点齿轮打开设置，点图钉切换始终置顶，点关闭按钮退出。
- 圆形小窗与完整计时窗都可通过右键菜单打开设置、切换置顶或退出。
- 提供打字小牛、开会小熊猫、赶日报的橘猫和改稿企鹅四个动效形象。
- 提供薰衣草紫、薄荷青、杏桃橙、冰川蓝和烟灰蓝五套主题。选择时同步预览，保存后记住组合。
- 重复启动会唤起已有窗口。配置采用临时写入后替换的方式保存，并保留一份有效备份。

默认组合为打字小牛、薰衣草紫和始终置顶。

## 收入与倒计时口径

金额按照用户填写的月薪、工作日期和上下班时间估算，上下班之间全程计薪。

设月薪为 `M`，当月工作日数为 `N`，每日工作时长为 `D`，今日已过的有效工作时长为 `T`。

```text
今日已赚 = M × T ÷ (N × D)
本月已赚 = M × (此前工作日数 × D + T) ÷ (N × D)
```

休息日和上班前，今日金额为 0。下班后，今日金额保留当天完整工作时长对应的数值。整月没有工作日时，两项金额均为 0。月中修改月薪或工作日期，会按新设置重新折算当月金额。

程序根据系统时间推算进度，关闭后重新打开也会显示当前估算值。

放假倒计时的目标为下一段休息前最后一个连续工作日的下班时间。例如勾选周六补班、周日休息后，倒计时目标会延至周六下班。法定假期和补班日期可通过自定义日历调整。

## 本地设置

设置保存在当前 Windows 用户的 `%LOCALAPPDATA%\WorkdayTimer\settings.xml`，备份文件为同目录下的 `settings.xml.bak`。主配置丢失或损坏时，程序会尝试恢复备份。

## 从源码构建

在安装了 .NET Framework 编译器和 WPF 程序集的 Windows 环境中，使用 PowerShell 进入项目目录后运行。

```powershell
.\build.ps1
```

默认在项目目录生成 `牛马打气机.exe`，也可指定输出文件。

```powershell
.\build.ps1 -OutputPath "$env:TEMP\moo-ney.exe"
```

构建脚本使用系统目录中的 .NET Framework C# 编译器，编译时会内嵌 `app.ico` 和 `Mascots` 下的角色资源。
